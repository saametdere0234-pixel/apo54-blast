# **App Name**: Lumina Grid

## Core Features:

- Dynamic 8x8 Game Engine: A high-performance interactive 8x8 grid that handles complex polyomino placement and state management.
- Comprehensive Block Arsenal: Implements all requested variants including Z, L, squares (3x3, 2x2), and various bar lengths (1x1 up to 5x1/1x5) with unique high-fidelity color coding.
- Explosive Line Clear System: Calculates horizontal and vertical matches with a signature 'pre-clear' flash animation tool before triggering cinematic visual explosions.
- AI Strategy Consultant Tool: A feature that analyzes current board states to suggest optimal placements for remaining blocks based on future clearance potential.
- Size-Weighted Scoring Engine: Real-time leaderboard and score calculations based on block size complexity and simultaneous line clearing combos.
- Automated Game Over Detection: Sophisticated algorithmic check that triggers the 'Game Over' overlay precisely when no further placements are mathematically possible.

## Style Guidelines:

- Primary Color: Electric Violet (#AB66FF) to drive a neon, arcade-style energy.
- Background Color: Deep Onyx (#0F0D12), a dark violet-tinted charcoal that makes vibrant block colors pop.
- Accent Color: Digital Azure (#7575FF) for highlights, scoring updates, and buttons to create high contrast.
- Headlines and Scores: 'Space Grotesk' (sans-serif) for its techy, geometric, and high-modernist feel.
- General UI and Body Text: 'Inter' (sans-serif) for maximum legibility in menu options.
- Centralized vertical stacking with the scoreboard docked at the top, a focal 8x8 grid, and a bottom-aligned 'Next Blocks' inventory tray.
- Juicy physics-based explosions with bloom effects and rhythmic pulsing highlights for lines slated for clearing.
